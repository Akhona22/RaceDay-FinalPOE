## Project Description

**RaceDay** is an ASP.NET Core MVC application integrated with an ASP.NET Core Web API. The application provides a platform for managing racing events, user accounts, and event categories.

The project demonstrates the implementation of web application development concepts, database integration, user authentication, and communication between an MVC application and a Web API.

## Features Implemented

- User Registration
- User Login
- Session Management
- User Dashboard
- Event Listing
- Event Creation
- Category Listing
- Category Management
- SQL Server Database Integration
- Entity Framework Core
- Git Version Control using GitHub

## Technologies Used

- **ASP.NET Core MVC** – Web application development
- **ASP.NET Core Web API** – Backend API functionality
- **C#** – Main programming language
- **Entity Framework Core** – Database management and ORM
- **SQL Server** – Relational database
- **GitHub** – Version control and project hosting
- **Visual Studio** – Development environment

## Getting Started

Follow the instructions below to run the RaceDay application locally.

### Prerequisites

Ensure that you have installed:

- Visual Studio
- .NET SDK
- SQL Server
- SQL Server Management Studio (SSMS)

### Running the Project

1. Clone or download the repository.
2. Open the solution file in Visual Studio.
3. Ensure that the database connection string is correctly configured.
4. Set the startup projects:
   - Right-click the solution in Solution Explorer.
   - Select **Configure Startup Projects** or **Set Startup Projects**.
   - Select **Multiple startup projects**.
5. Set the following projects to **Start**:
   - `RaceDay.API`
   - `RaceDay.MVC`
6. Click **Apply** and **OK**.
7. Run the solution.

Both the API and MVC projects should start, allowing the application to communicate with the backend API.

## Project Structure

The solution consists of two main projects:

- **RaceDay.API** – Handles backend functionality and API operations.
- **RaceDay.MVC** – Handles the user interface and user interactions.
